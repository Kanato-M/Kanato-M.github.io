🔢 遊び方How to play

各行・各列・各3×3ブロックに 1〜9 が1つずつ入るように、空いたマスを埋めましょう。答えは必ず1通りです。

  • マスを選んで数字パッド（またはキーボード 1〜9）で入力。←↑→↓ で移動、Backspace/0 で消去。
  • メモモード（Nキー / Shift+数字）で候補を小さく書き込めます。数字を確定すると同じ行・列・ブロックのメモは自動で消えます。
  • 同じ数字の重複は赤く表示。「ミスを表示」をONにすると正解と違う数字も赤くなります。
  • ヒントは選択中（または次に埋めやすい）マスに正解を1つ入れます。Ctrl+Z/Y で戻す・やり直し。
  • 途中経過は自動保存。タブを離れるとタイマーは止まります。

Fill the grid so every row, every column and every 3×3 box contains the digits 1–9 exactly once. Every puzzle has exactly one solution.

  • Select a cell, then tap the number pad (or press 1–9). Move with ←↑→↓, clear with Backspace/0.
  • Notes mode (N key, or Shift+digit) writes small candidates. Placing a digit removes that note from its row, column and box.
  • Duplicate digits are shown in red. Turn on “Show mistakes” to also flag digits that differ from the solution.
  • Hint fills one correct digit in the selected (or the easiest) cell. Ctrl+Z/Y undo / redo.
  • Your game is saved automatically; the timer pauses while the tab is hidden.
