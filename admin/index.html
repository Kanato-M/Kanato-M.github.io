旅行の写真や各ページのデータを、ブラウザから直接 GitHub リポジトリに保存（コミット）します。書き込み権限のあるトークンを持つ人（＝あなた）だけが編集できます。 Edit page data and upload travel photos, committed straight to the GitHub repository from your browser. Only someone holding a token with write access (you) can make changes.

GitHub に接続Connect to GitHub

トークンの作り方（初回のみ）How to create a token (once)
  1. GitHub の Settings → Developer settings → Fine-grained tokens → Generate new token を開くOpen Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → このサイトのリポジトリだけを選ぶRepository access: Only select repositories → pick only this site's repository
  3. Permissions → Repository permissions → Contents: Read and write（他は不要）Permissions → Repository permissions → Contents: Read and write (nothing else)
  4. 有効期限を設定して作成し、上の欄に貼り付けて「接続」Set an expiry, generate, paste it above and press Connect

トークンはこのブラウザ内（localStorage / sessionStorage）にだけ保存され、サイトのファイルには一切書き込まれません。共用 PC では「記憶」をオフにしてください。万一漏れた場合は GitHub 上でトークンを削除すれば無効になります。 The token is stored only in this browser (localStorage / sessionStorage) and never written into the site. Leave “Remember” off on shared computers. If it ever leaks, delete it on GitHub and it stops working immediately.
